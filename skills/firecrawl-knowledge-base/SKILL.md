# firecrawl-knowledge-base

Builds structured LLM-ready Markdown knowledge bases, RAG chunks, and training JSONL corpora.

## Alur kerja

1. Tentukan lingkup URL yang disetujui dan hak penggunaan konten.
2. Ekstrak bagian relevan dengan metadata sumber, bersihkan duplikat, dan beri ID potongan stabil.
3. Keluarkan Markdown atau JSONL, uji sampel retrieval, dan simpan rujukan untuk setiap potongan.
