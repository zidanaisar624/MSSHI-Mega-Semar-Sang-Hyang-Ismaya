# creative-thinking-for-research

Applies 8 cognitive science frameworks for creative thinking: Combinatorial Bisociation, Problem Reformulation, Structure-Mapping Analogy, Boden's Constraint Manipulation, TRIZ Negation, Abstraction Laddering, Adjacent Possible, and Janusian Dialectical Thinking.

## Workflow

1. Write the original problem and the assumptions that make it difficult. Identify which constraints are fixed and which can be varied.
2. Choose two lenses with clear payoff: bisociation, reformulation, structure-mapping analogy, constraint manipulation, TRIZ negation, abstraction laddering, adjacent possible or Janusian thinking.
3. Translate each reframing into a testable proposal. When using analogies, map the relationships explicitly and state where the analogy breaks.
4. Return candidate, reasoning lens, falsifiable claim, smallest test and risks. Keep speculation separate from validated findings.
