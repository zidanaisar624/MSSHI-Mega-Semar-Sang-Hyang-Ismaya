# match-my-writing-style

Builds and applies a persistent Voice Card so every piece of writing matches the user's authentic voice.

## Workflow

1. Collect a few representative samples the user has authorized, plus target audience, language and purpose. Ask before retaining samples or a long-lived style profile.
2. Build a Voice Card with register, sentence rhythm, word choices, structural habits, concrete examples of preferred phrasing and constraints. Note where evidence is thin.
3. Apply the card to a short trial passage. Preserve claims, references and author ownership. Compare source and rewrite for factual drift, awkward mimicry and context fit.
4. Return the rewrite and a portable Voice Card the user can edit. Save the card only at their chosen private path, with sensitive excerpts excluded.
