# slide-generation

Converts completed LaTeX papers into 16:9 Beamer presentation slides or academic posters.

## Workflow

1. Read the complete paper, figures and target format. Record audience, speaking time, template, citations and which results are supported.
2. Outline one claim per slide. Use 16:9 Beamer for talks and venue dimensions for posters. Preserve methods, evidence, uncertainty and conclusions. Reuse verified figures and trim derivations to relevant details.
3. Build editable LaTeX sources with portable asset paths, readable typography and complete citations. Keep detailed methods or extra figures in an appendix where helpful.
4. Compile if a compatible LaTeX engine is available. Review every rendered page for clipping, citation resolution and contrast. Return sources plus verified output, or the source and exact compile blocker.
