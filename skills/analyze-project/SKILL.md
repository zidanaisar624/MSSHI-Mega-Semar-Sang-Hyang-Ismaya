# analyze-project

Rigor Analyze / Rigor Audit read-only skill for deep learning research repositories, mapping entrypoints, config relationships, allowed change zones, and suspicious implementation heuristics.

## Alur kerja

1. Petakan entrypoint, konfigurasi aktif, jalur data, model dan skrip evaluasi dengan baca kode.
2. Buktikan dugaan risiko dengan path dan baris kode. Pisahkan potensi masalah dari bug yang bisa direproduksi.
3. Hasilkan diagram alur ringkas dan daftar pemeriksaan sebelum perubahan.
