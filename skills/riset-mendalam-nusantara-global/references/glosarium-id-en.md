# Glosarium Metodologi & Publikasi Ilmiah (Indonesia ↔ Inggris)

Rujukan cepat istilah akademik dwibahasa (orisinal MSSHI) agar penulisan naskah Indonesia (EYD V) dan Inggris (*academic English*) tetap konsisten.

| Istilah Indonesia | Istilah Inggris | Makna Ringkas |
| --- | --- | --- |
| Abstrak terstruktur | *Structured abstract* | Ringkasan artikel terbagi atas Latar Belakang, Metode, Hasil, dan Simpulan |
| Analisis daya statistik | *Statistical power analysis* | Perhitungan ukuran sampel minimum untuk mendeteksi efek nyata pada $\alpha$ dan $1-\beta$ tertentu |
| Analisis sensitivitas | *Sensitivity analysis* | Pengujian ketahanan temuan saat asumsi, outlier, atau spesifikasi model diubah |
| Bias konfirmasi | *Confirmation bias* | Kecenderungan hanya memilih bukti yang mendukung hipotesis awal |
| Bias publikasi | *Publication bias* | Kecenderungan studi dengan hasil signifikan lebih sering diterbitkan dibanding hasil nol |
| Bias seleksi | *Selection bias* | Ketidakseimbangan karakteristik sampel terhadap populasi sasaran |
| Celah penelitian | *Research gap* | Bagian pengetahuan atau bukti yang belum terjawab secara memadai oleh studi terdahulu |
| Daftar periksa pelaporan | *Reporting guideline / checklist* | Standar butir wajib pelaporan studi (PRISMA, CONSORT, STROBE, COREQ, TRIPOD) |
| Daya generalisasi / Validitas eksternal | *External validity / Generalizability* | Sejauh mana temuan berlaku di luar sampel atau latar penelitian |
| Definisi operasional | *Operational definition* | Penjabaran konsep abstrak menjadi indikator dan cara pengukuran yang konkret |
| Dependabilitas | *Dependability* | Konsistensi dan keterlacakan proses analisis dalam riset kualitatif (*audit trail*) |
| Desain kuasi-eksperimen | *Quasi-experimental design* | Desain eksperimen tanpa pengacakan penuh ke kelompok perlakuan dan kontrol |
| Desain metode campuran | *Mixed-methods design* | Integrasi sistematis data kuantitatif dan kualitatif dalam satu penelitian |
| Desain potong lintang | *Cross-sectional design* | Pengambilan data pada satu titik waktu tertentu |
| Desain longitudinal | *Longitudinal design* | Pengamatan subjek yang sama secara berulang lintas waktu |
| Galat Tipe I / Tipe II | *Type I ($\alpha$) / Type II ($\beta$) error* | Salah menolak $H_0$ yang benar (*false positive*) / gagal menolak $H_0$ yang salah (*false negative*) |
| Hipotesis nol / alternatif | *Null ($H_0$) / Alternative ($H_1$) hypothesis* | Pernyataan tidak adanya efek/perbedaan vs pernyataan adanya efek/perbedaan |
| Interval kepercayaan | *Confidence interval (CI)* | Rentang estimasi parameter populasi pada tingkat keyakinan tertentu (mis. 95% CI) |
| Jejak audit | *Audit trail* | Dokumentasi runtut atas keputusan pengodean, data, dan analisis |
| Kaji ulang sejawat | *Peer review* | Penelaahan kritis naskah oleh pakar sejawat sebelum diterbitkan |
| Kebaruan penelitian | *Research novelty* | Nilai tambah orisinal pada teori, metode, data, atau konteks yang belum ada sebelumnya |
| Kebocoran data | *Data leakage* | Masuknya informasi dari data uji/masa depan ke tahap pelatihan atau pemodelan |
| Kerangka pemikiran / konseptual | *Conceptual framework* | Peta hubungan logis antar-konstruk dan variabel berdasarkan teori & bukti |
| Keterlacakan balik | *Backward traceability* | Kemampuan melacak setiap klaim balik ke halaman/tabel/DOI sumber aslinya |
| Kredibilitas | *Credibility* | Kepercayaan atas kebenaran temuan kualitatif (triangulasi, *member checking*) |
| Kuesioner / Angket | *Questionnaire / Survey instrument* | Daftar pertanyaan terstruktur untuk menghimpun data dari responden |
| Nilai p | *p-value* | Peluang memperoleh data seekstrem pengamatan bila hipotesis nol benar (bukan ukuran besarnya efek) |
| Pengambilan sampel bertujuan | *Purposive sampling* | Pemilihan partisipan secara sengaja berdasarkan kriteria kesesuaian dengan tujuan riset |
| Pengambilan sampel acak berstrata | *Stratified random sampling* | Pengacakan sampel secara proporsional/terukur dari subkelompok populasi |
| Pengodean terbuka / aksial / selektif | *Open / axial / selective coding* | Tahapan analisis kualitatif dari pelabelan awal hingga integrasi tema inti |
| Persetujuan setelah penjelasan | *Informed consent* | Kesediaan sukarela partisipan setelah memahami tujuan, risiko, dan hak kerahasiaan |
| Preregistrasi | *Preregistration* | Pendaftaran protokol, hipotesis, dan rencana analisis secara terbuka sebelum analisis data |
| Reliabilitas | *Reliability* | Konsistensi hasil pengukuran bila instrumen diulang dalam kondisi serupa |
| Replikabilitas / Reprodusibilitas | *Replicability / Reproducibility* | Kemampuan studi diulang atau hasil komputasi dihitung ulang dengan data & kode yang sama |
| Saturasi data | *Data / thematic saturation* | Titik ketika penambahan informan tidak lagi memunculkan tema konseptual baru |
| Sumber primer vs sekunder | *Primary vs secondary source* | Laporan data/penelitian asli vs ringkasan/kutipan dari penulis lain |
| Tanggapan penelaah | *Rebuttal / Response to reviewers* | Dokumen jawaban sistematis poin demi poin terhadap komentar *peer reviewer* |
| Tinjauan literatur sistematis | *Systematic literature review (SLR)* | Sintesis literatur dengan protokol eksplisit, kriteria inklusi/eksklusi, dan pelaporan transparan |
| Triangulasi | *Triangulation* | Pemeriksaan silang temuan menggunakan beragam sumber, metode, atau peneliti |
| Ukuran efek | *Effect size* | Besaran praktis hubungan atau perbedaan (mis. Cohen's $d$, $r$, $\eta^2$, $R^2$, Odds Ratio) |
| Uji kelayakan etik | *Ethical clearance / IRB approval* | Persetujuan komite etik penelitian sebelum melibatkan partisipan manusia atau data sensitif |
| Validitas internal | *Internal validity* | Keyakinan bahwa perubahan variabel hasil benar-benar disebabkan perlakuan, bukan pengganggu |
| Validitas konstruk | *Construct validity* | Ketepatan instrumen dalam mengukur konstruk teoretis yang dimaksud |
| Variabel mediator | *Mediating variable* | Variabel perantara yang menjelaskan mekanisme *mengapa* X memengaruhi Y |
| Variabel moderator | *Moderating variable* | Variabel yang memperkuat atau memperlemah hubungan X terhadap Y |
| Variabel pengganggu / perancu | *Confounding variable* | Variabel luar yang berkaitan dengan X dan Y sehingga dapat mendistorsi estimasi hubungan |
