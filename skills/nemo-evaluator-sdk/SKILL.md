# nemo-evaluator-sdk

Evaluates LLMs across 100+ benchmarks from 18+ harnesses using NVIDIA NeMo Evaluator SDK.

## Alur kerja

1. Pilih task, versi NeMo, model dan kebutuhan perangkat dari dokumentasi resmi.
2. Tinjau dataset, kuota dan kredensial. Jalankan uji kecil di lingkungan yang terisolasi setelah disetujui.
3. Simpan konfigurasi, metrik, waktu, biaya dan batas perbandingan.
