# data-analysis

Generates statistical analysis code with 4-round review, parametric/non-parametric test selection, effect sizes, confidence intervals, and formatted p-values.

## Alur kerja

1. Periksa skema, missingness, unit analisis, kebocoran, desain sampel, dan pertanyaan penelitian.
2. Pilih metode dari desain, distribusi dan asumsi. Buat kode dengan seed bila relevan dan pisahkan eksplorasi dari konfirmasi.
3. Laporkan ukuran efek, ketidakpastian, ukuran sampel, asumsi dan cara reproduksi.
