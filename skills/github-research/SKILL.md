# github-research

Explores and analyzes GitHub repositories across 6 phases: Intake, Discovery, Filtering, Deep Dive, Matrix Analysis, and Integration Blueprint.

## Alur kerja

1. Definisikan kebutuhan, bahasa, lisensi, dan batas integrasi. Kumpulkan repo dari sumber resmi.
2. Periksa README, rilis, lisensi, aktivitas dan entrypoint tanpa menjalankan kode unduhan.
3. Buat matriks kecocokan dengan commit atau tag, biaya setup, bukti, dan langkah uji sandbox.
