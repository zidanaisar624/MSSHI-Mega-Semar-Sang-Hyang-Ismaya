# explore-run

Rigor Improve / Rigor Explore run leaf skill for budget-aware exploratory variant matrices and short-cycle trials.

## Alur kerja

1. Definisikan grid eksperimen, budget, seed, dan kriteria penghentian.
2. Lakukan smoke test untuk satu konfigurasi sebelum memperbesar cakupan. Simpan run ID dan konfigurasi efektif.
3. Urutkan hasil beserta variasi antar-run. Laporkan kegagalan dan biaya aktual.
