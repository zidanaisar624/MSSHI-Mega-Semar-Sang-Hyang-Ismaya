# explore-code

Rigor Improve implementation leaf skill for auditable candidate code adaptations on an isolated branch or worktree.

## Alur kerja

1. Baca artefak audit, tentukan area yang boleh diubah, dan ambil baseline reproducible.
2. Ubah satu hipotesis dalam cabang atau workspace terpisah. Pertahankan API dan data asli.
3. Sajikan diff, uji yang relevan, dampak pada metrik, dan alasan mempertahankan atau menolak kandidat.
