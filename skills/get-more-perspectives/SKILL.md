# get-more-perspectives

Convenes a virtual 5-expert advisory panel (Operator, Skeptic, Visionary, Customer Advocate, Finance Mind) to stress-test decisions.

## Workflow

1. Write the decision, constraints, alternatives and what evidence could change it. Use the five perspectives as reasoning lenses unless real delegation is explicitly in scope.
2. Have Operator test execution, Skeptic expose failure modes, Visionary look for upside, Customer Advocate test user impact, and Finance Mind examine cost and downside.
3. Compare independent observations, overlaps and disagreements. Check each claim against available evidence and flag assumptions.
4. Recommend a path with its strongest objection, an early indicator, and a reversible experiment. Report disagreement rather than inventing consensus.
