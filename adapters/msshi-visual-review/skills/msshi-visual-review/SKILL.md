# MSSHI Visual Review

Use this workflow when the user asks to review or update MSSHI visuals. Start from the checkout they named. Read `assets/README.md` to match each diagram to its source. Inspect `configs/bot_role_and_skill_matrix.json` and `docs/ALUR_PRESET_MUZA.md` before changing any persona label or handoff.

1. Check that setup diagrams distinguish four modes and that the role map shows both delegation and return of results. Match names and counts to the user's matrix.
2. Check the creative diagram for concept approval, editable projects, review, and final approval. Preserve both the short-video route and the 10–40 minute route with chapter review.
3. Verify that the academic map has seven workflows, the context map has five layers, and the integration map distinguishes bundled skills, local apps, and account services.
4. If asked to edit, change the SVG, README text, and relevant Mermaid together. Validate XML, titles and descriptions, links, and readability at a narrow size.
5. If requested, refresh the editable Higgsfield Canvas using only approved diagram labels. Use the local SVG files for the README package.
