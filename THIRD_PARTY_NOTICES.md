## Preserved upstream files

The integrations installer copies per-skill LICENSE/NOTICE files and records Git blob and SHA-256 hashes for downloaded snapshots. It uses distinct anthropic-* and hf-* names to preserve existing user skills. Its local dreaming adapter schedules only the deterministic proposal pass. It does not run the upstream agent-waking cron templates.

The OmniVoice plugin declares Apache-2.0 in pyproject.toml but does not ship a standalone LICENSE at the pinned revision. Its source is cached for local use and referenced here, not bundled into the public MSSHI distribution. The separate k2-fsa/OmniVoice runtime code is Apache-2.0. Its pretrained model weights are CC-BY-NC according to the official model card (reviewed 2026-11-11). Personal local tests are configured here. Commercial narration or redistribution requires compatible rights. Audio-tokenizer notices are retained.

Any reported token saving or throughput is an upstream benchmark from a specific workload. MSSHI does not guarantee those percentages or speeds.

CC0 applies only to assets with an explicit CC0 license file. Academic references and public theories do not grant a blanket license to copy their source texts.
