# Koneksi layanan manual - MSSHI v3.1.2

MSSHI tidak memasang atau mengaktifkan GitLab, Tinyfish, BrightData, atau Steel melalui wizard. Flag layanan lama diterima untuk kompatibilitas dan memberi penjelasan; tidak membuat koneksi atau membagikan cache OAuth antarbot.

Jika diperlukan, sambungkan layanan sendiri melalui pengaturan resmi Hermes/layanan terkait. Gunakan kredensial milik sendiri, batasi izin sesuai proyek, dan periksa biaya/kuota layanan. Rahasia tidak dimasukkan ke SOUL, template, repo Git, atau PDF publik. Status konektor lokal bukan bukti sebuah operasi layanan berhasil.

Pilihan browser berada pada langkah Browser & Akun di `msshi setup`. Tidak ada cookie/akun yang dipindahkan dan tidak ada browser yang dibuka otomatis. Instalasi pengguna lama tidak menghapus koneksi buatan pengguna; pemutusan hanya dilakukan ketika pengguna memintanya.
