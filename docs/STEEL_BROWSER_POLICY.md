# Pilihan browser manual - MSSHI v3.1.2

Rute Steel lama telah dihentikan pada revisi v3.1.2 ini. Installer tidak memasang browser cloud atau memindahkan akun. Nama file ini dipertahankan agar tautan lama tetap bisa dibaca.

Gunakan `msshi setup` untuk memilih Chrome, Edge, Firefox, atau tidak memilih browser. Label akun/profil hanyalah catatan pilihan, bukan sesi login atau token autentikasi. Masuklah sendiri melalui browser yang dipilih. Tidak ada penyalinan cookie, pembacaan akun, atau pembukaan browser saat setup/startup.

`msshi browser --status` adalah pemeriksaan lokal. Flag pemasangan Steel lama dipertahankan hanya untuk memberi penjelasan penghentian; tidak mengunduh atau mengaktifkan layanan. Memilih browser tidak menjamin kendali otomatis tersedia pada setiap host. Untuk tugas yang butuh akun pribadi, periksa kemampuan host dan persetujuan pengguna sebelum memakai sesi tersebut.
